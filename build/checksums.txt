# SHA-256 of every native Agora macOS SDK archive this repository downloads. The fetch scripts
# (build/fetch-*.sh) refuse to stage an archive whose hash is not listed here, so this file is the
# trust anchor for the native code — nothing is bound that was not pinned here first.
#
# Format, one per line:
#   <artifact>-<version> <sha256>
# where <artifact> is the download's base name (AgoraRtcEngine_macOS, AgoraAudio_macOS, ...) — the
# Video and Voice archives may share a version number, so the version alone would be ambiguous;
# the artifact name keeps them distinct.
#
# For products built from source rather than downloaded (Whiteboard, via netless), the pin is a
# git commit instead:
#   git:<owner>/<repo>@<tag> <40-hex-commit>
# because netless re-tags releases, so a tag alone is not a stable anchor.
#
# To add or update a hash, download the archive and run:
#   shasum -a 256 <file>            # or: sha256sum <file>
# and confirm the version is the one actually published:
#   curl -s https://trunk.cocoapods.org/api/v1/pods/AgoraRtcEngine_macOS | python3 -m json.tool
#
