## What's changed

**Native macOS support debuts.** The first release of `Net.Agora.Mac` — .NET for macOS (AppKit)
bindings over Agora's native **macOS** RTC SDK, `AgoraRtcEngine_macOS 4.6.2`. This is the desktop
path Mac Catalyst cannot be: Agora ships no `maccatalyst` slice, so a MAUI app cannot link Agora on
the Mac, but a native `net*-macos` app can, and these are its bindings.

- **`Net.Agora.Video.Mac` 4.6.2.1** — join a channel and publish/subscribe audio and video,
  rendering into an `NSView`. Hand-written against the real `AgoraRtcEngineKit.h`, scoped to the
  cross-platform client's needs. The iOS-only audio-route and camera-switch selectors
  (`setEnableSpeakerphone:`, `setDefaultAudioRouteToSpeakerphone:`, `switchCamera`) are deliberately
  not bound — the macOS engine does not implement them.
- **`Net.Agora.Voice.Mac` 4.6.2.1** — the audio-only surface of the same engine. Unlike iOS there
  is no separate voice-only build, so it carries the same frameworks as Video (`video_dec`
  included) and offers an audio-only API rather than a smaller payload.
- **Twelve `Net.Agora.Extensions.<Name>.Mac` 4.6.2.1** packages — the RTC feature extensions (AI
  noise suppression, virtual background, spatial audio, the enhancement filters, the software
  encoders and the rest), native payload only, staged from the same archive.

Every package ships `net8.0-macos`, `net9.0-macos` and `net10.0-macos`, one universal
`macos-arm64_x86_64` slice each (there is no simulator on macOS). The engine's create → drive →
destroy round-trip is verified on the host by `tests/Net.Agora.Mac.DeviceTests`.
