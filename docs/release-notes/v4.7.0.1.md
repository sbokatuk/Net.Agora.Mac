## What's changed

`Net.Agora.Video.Mac`, `Net.Agora.Voice.Mac` and the twelve `Net.Agora.Extensions.*.Mac` packages
advance to **4.7.0.1**: the native SDK moves from `AgoraRtcEngine_macOS` 4.6.2 to **4.7.0**, and the
binding revision resets to 1. This is the bump the daily upstream check asked for in
[#8](https://github.com/sbokatuk/Net.Agora.Mac/issues/8).

The managed API doesn't change. All 77 selectors the two bindings export are still in the 4.7.0
binary, and the engine's delegate protocol differs only in its comments.

`Net.Agora.Signaling.Mac` has to move with this release, because its `aosl` comes out of the same
archive. Use **2.3.0.2** alongside 4.7.0.1. See the
[`signaling-v2.3.0.2` note](https://github.com/sbokatuk/Net.Agora.Mac/releases/tag/signaling-v2.3.0.2).

## Packaging changes

- **`Net.Agora.Extensions.VideoEncoder.Mac` now carries one framework, not two.**
  `video_enc.xcframework` is gone from the 4.7.0 archive and `AgoraVideoEncoderExtension` no longer
  links it. The extension binary grows from about 150 KB to 1.7 MB, so the codec appears to have
  moved inside it. Nothing changes for an app that only references the package. A build step that
  names `video_enc.framework` needs updating.
- **`aosl` moves from 1.3.5 to 1.3.16.** The six frameworks in `Net.Agora.Video.Mac` and
  `Net.Agora.Voice.Mac` are otherwise the same list, and `AgoraRtcKit` still links the same five
  dependencies.

The minimum deployment target stays at macOS 12.0.

## What 4.7.0 brings natively

From [Agora's RTC release notes](https://docs.agora.io/en/video-calling/overview/release-notes?platform=macos),
which don't label these versions by platform, so not every line is certain to apply to macOS:

- H.265 encode and decode where the device's hardware supports it, falling back to AV1 or H.264.
- Lower CPU use, a faster first frame and lower latency when co-hosting one to one.
- Fixes for residual audio after an audience-to-host switch and after `stopEffect` then `playEffect`,
  and for the local audio state callback during system calls or when the audio device is in use.
- From 4.6.3 and 4.6.4: fixes for crashes during audio and video interaction, a frozen preview with
  a custom renderer, `onNetworkQuality` after an outage, and Web interop encoding failures.

These arrive with the native framework and need nothing from the managed side.

One change in the headers is worth knowing if you handle connection failures yourself. Agora now
spells out the recovery from `AgoraConnectionState.Failed`: call `LeaveChannel`, wait for
`Disconnected`, then join again with a new token. Joining without leaving first returns -17.

## Not bound

The binding stays scoped to what the cross-platform clients need, so these 4.7.0 additions aren't
bound: `setRemoteRenderRotation:rotation:` with `AgoraVideoRotation`, `AgoraRtcChannelMediaOptions.channelType`
(a technical preview), the metadata fields on video frames, `AgoraRtcEngineConfig.parameters`, and
the new error codes 1700–1707 and 2007–2013. `AgoraErrorCode` was already not exhaustive: cast to
`int` to read them.

## Verified

Against a secured Agora project, with short-lived tokens signed for a channel used by nothing else:

- `samples/Net.Agora.Sample.Video.Mac` on net8 and net9, and the `Net.Agora` Video.Mac sample on
  net9: the app joins, reports the remote user and renders remote video. The net9 samples also
  render the local camera, and a camera stream reached a second sample's Remote pane intact. Forced
  garbage collections every second didn't stall any of them.
- The `Net.Agora` Voice.Mac sample on net9: it joins, shows live microphone levels, and reports a
  remote speaker by uid at a real volume, peaking at 133 of 255. The SDK log shows the remote audio
  decoded.
- An expired token surfaces as `TokenExpired`. A token for another channel, or none, surfaces as
  `InvalidToken`.
- The package tests and the host smoke suite pass for Video and Voice on `net8.0-macos15.0`,
  `net9.0-macos15.0` and `net10.0-macos26.0`.

The live checks used `net8` and `net9` only: no sample targets `net10.0-macos26.0`.
