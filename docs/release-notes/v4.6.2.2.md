## What's changed

`Net.Agora.Video.Mac`, `Net.Agora.Voice.Mac` and the twelve `Net.Agora.Extensions.*.Mac` packages
advance to **4.6.2.2**. The native SDK is unchanged at AgoraRtcEngine_macOS 4.6.2; what changed is
the C# surface, mirroring what landed in the iOS bindings.

### The engine's delegate is exposed as C# events

`AgoraRtcEngineDelegate` is an all-optional protocol on a class with a single delegate slot, so every
bound callback is now an event on the engine:

```csharp
engine.DidJoinedOfUid += (_, e) => Attach(e.Uid);
engine.ConnectionChangedToState += (_, e) => Log(e.State, e.Reason);
```

Ten events on Video, nine on Voice. The event and `EventArgs` names match the iOS bindings exactly,
so code moving between the two platforms does not have to change.

The same caveat applies as on iOS: **events and a hand-assigned delegate are mutually exclusive**,
because subscribing an event installs the generator's own delegate in place of whatever was set.
Pick one style per engine instance. The `Delegate`/`WeakDelegate` pair is bound for the subclass
style; it is weak, so keep your delegate rooted.

### `new AgoraRtcEngineKit()` no longer compiles

The engine only exists through `SharedEngine`; the implicit public constructor compiled and returned
an object that was not the shared engine. It now carries `[DisableDefaultCtor]` — deliberately
source-breaking for code that was already broken.

### Unchanged, and worth repeating

`switchCamera`, `setEnableSpeakerphone:` and `setDefaultAudioRouteToSpeakerphone:` remain unbound.
They are declared in the shared `AgoraRtcEngineKit.h` but the macOS engine raises "unrecognized
selector" for them — verified on the host smoke suite. A Mac routes audio and video by device
selection instead. That device-selection API is itself not bound yet.

## Packages

| Package | Version | Native |
| --- | --- | --- |
| `Net.Agora.Video.Mac` | 4.6.2.2 | AgoraRtcEngine_macOS 4.6.2 (6 xcframeworks, one universal slice) |

against the net10 leg requires Xcode 26.0. Minimum deployment target is macOS 12.0.
